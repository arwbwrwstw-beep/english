English Journey — طريقة التشغيل
1) أبسط طريقة: افتح index.html بمتصفح الحاسبة (Chrome أو Edge أو Safari).
2) للتثبيت على الموبايل والعمل دون إنترنت: ارفع كل ملفات هذا المجلد إلى استضافة ثابتة تدعم HTTPS (مثل GitHub Pages)، افتح الرابط مرة بالإنترنت، ثم اختر "إضافة إلى الشاشة الرئيسية".
3) الصوت من أصوات جهازك؛ عمله دون إنترنت يعتمد على الأصوات الإنجليزية المثبتة.
4) تقدمك محفوظ في المتصفح الذي تستعمله فقط. لنقله: الإعدادات > تصدير، ثم استيراد في المكان الجديد.
